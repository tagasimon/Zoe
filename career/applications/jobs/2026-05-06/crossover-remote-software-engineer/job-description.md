## Description

Crossover hires remote software engineers from Uganda for long-term engagements with international product companies. Roles typically involve full-stack development across Python, Java, or .NET stacks; API development and integration; working asynchronously with global teams. Crossover uses an assessment process before matching candidates to client companies. Requirements: strong full-stack software engineering skills; professional-level English; ability to work remotely with minimal supervision. Mid-to-senior level. Competitive USD compensation.
